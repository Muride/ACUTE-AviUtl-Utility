# ACUTE-AviUtl-Utility
AviUtl向け ジェットカット＆AI文字起こし自動化ツール

**ACUTE** は、動画編集ソフト「AviUtl ExEdit2」向けの作業自動化ツールです。
ジェットカットと字幕起こしを全自動で行って.aup2を出力してくれるツールが欲しいなと思ったので、作りました。というかGeminiに作らせました。
プログラミングほぼ初心者の状態からGeminiに教えてもらいつつ進めたので、多分なんか色々変なところはあると思いますが、とりあえず私が自分で使う分には問題ないくらいになったので公開します。

## 主な機能

1. **無音カット（JetCut）**
   - 動画の無音区間を自動で検知してカットします。
2. **文字起こし・字幕生成（Whisper）**
   - faster-whisperを使い、音声を自動でテキスト化→字幕の配置が行えます。字幕のスタイルはエイリアスの.objectファイルをインポートして設定することも可能です。
3. **Geminiによる高度なテキスト補正**
   - 「Gemini」のAPIキーを入力することで、Whisperの誤変換（同音異義語など）を文脈から自動修正できます。
4. **AviUtlでそのまま使える**
   - 処理が終わると.aup2ファイルが生成されます。AviUtlに読み込むと、カット済みの動画と字幕テロップがタイムラインに並びます。

## 導入方法

1. (AviUtl入れてる人なら大丈夫かと思いますが)ffmpegをインストールし、環境変数pathを通しておいてください。
2. Releasesから**ACUTE_vX_X_X.exe**をDLし、ZIPファイルを好きな場所で解凍します。
3. フォルダの中に入っている **ACUTE_vX_X_X.exe** をダブルクリックして起動します。
   - **注意**: `ACUTE_vX_X_X.exe` と同じ場所にある `_internal` フォルダは絶対に消したり移動したりしないでください（起動できなくなります）。デスクトップから起動したい場合は、ショートカットを作成してください。

## 使い方

1. **ファイルの読み込み**
   - ベースとなる動画ファイルを画面左上の入力欄にドラッグ＆ドロップします。
   - 別撮りの音声(頭は合わせてある)がある場合は、「文字起こし用音声」に追加できます。
2. **カット＆字幕の設定**
   - 無音カットの感度（dB）や、字幕のフォント・色を設定します。
   - 閾値(dB): この音量より小さい部分を「無音」とみなします。
   - 無音秒数(s): この秒数以上無音が続いた場合にカットします。
   - 余白(f): カットした区間の前後に残す予備フレーム数です(子音等が消えるのを防ぐため)。
   - 「フィラー除去」にチェックをつけると、字幕から「えー」や「あのー」といったフィラーが取り除かれます。(チェックをつけていなくてもwhisper側で勝手に取り除かれる場合もあります。)
3. **AIモデルの設定**
   - 右画面で、Gemini APIキー（取得無料）を入力すると、テキストの自動校正が有効になります。
   - 「動画の内容」や「よく間違えられる固有名詞」をAIに教えておくと、さらに精度が上がります。
4. **処理開始**
   - 一番下の「処理開始」ボタンを押します。（※初回はAIモデルの読み込みに少し時間がかかります）
   - 完了すると、動画と同じフォルダに .aup2ファイルが生成されます。
